# Scissors vs forceps:
#   * jaw CENTER = blades JUST TOUCHING. Fully closed = blades overlapping, which needs a lot of force; so M2
#     closing onto M5 should stall at the touch -> the same contact test as forceps finds the center.
#   * roll/pitch: forceps values, but the scissors' own expected ranges (measured at slow speed, 4 Nov):
#     roll ~ forceps, PITCH ~1990 vs forceps 1704.
#   * everything marked UNMEASURED is a forceps value used as a starting point; measure with verify runs:
#       ros2 launch arts_dv_tool_driver tool_homing.launch.py arm:=<arm with FTBEQBRA> tool:=scissors verify:=true calibrate:=true  (the launch offers scissors on FTBEO5G1 only)

# ---------------- jaws: finding the center ----------------
# Same method as forceps: M5 from its load step (or engaged start); M2 closes until it TOUCHES M5.
# The engaged/step thresholds below are forceps-validated; scissors data will show whether they hold.
# Scissors M5: the blades drag M2's (not yet engaged) blade along, so M5 is near its current limit from the
# start (friction, NOT engagement), never shows a free-spin step, and stops after ~300-390 ticks -> the
# fallback rule (center = start - m5_engaged_start) places it. M5 must come back well past its start, against
# friction (hence jaw.move_current). M2 then closes onto M5 and stops at the touch.
jaw.m5_step_offset 107           # UNMEASURED (forceps value); default if the adapter has no entry below
jaw.m2_step_offset 139           # UNMEASURED (forceps value)
jaw.m2_contact_offset -4         # contact - true touch: -4, -5 (psm2, 4 Nov); same as forceps
jaw.m2_apply_contact_offset false # false: M2 parks AT the detected contact (offset only cross-checks it)
jaw.m2_center_snap_max 300       # (only with <adapter>.m2_center_angle) M2 snaps after the contact only within this
jaw.m5_center_snap_max 300       # (only with <adapter>.m5_center_angle) step mode snaps M5 only within this
jaw.m5_engaged_start 267         # M5 sweep start - true center: 246, 252, 304 (psm2, 4 Nov; forceps 63)
jaw.engaged_trend 1.10           # M5 "engaged at start": current climb 450-600 vs 150-300 ticks
jaw.m2_engaged_trend 1.06
