# Needle driver vs scissors:
#   * jaw CENTER = jaws JUST TOUCHING (like scissors): M2 closes onto M5 and the contact test finds the touch.
#   * every value is a SCISSORS value for now. Learn this tool with calibration runs (slow, jog each jaw to its
#     true center with the sticks + A; at the end A saves the measured values into this file, B discards):
#       ros2 launch arts_dv_tool_driver tool_homing.launch.py arm:=<arm with FTBEO5G1> tool:=needledriver calibrate:=true config_dir:=<source config/homing>
#   * roll/pitch expected ranges 0 = never fast until calibrated. Per-adapter step offsets get added by calibration.

# ---------------- jaws: finding the center ----------------
# Same method as forceps: M5 from its load step (or engaged start); M2 closes until it TOUCHES M5.
# The engaged/step thresholds below are forceps-validated; scissors data will show whether they hold.
# Scissors M5: the blades drag M2's (not yet engaged) blade along, so M5 is near its current limit from the
# start (friction, NOT engagement), never shows a free-spin step, and stops after ~300-390 ticks -> the
# fallback rule (center = start - m5_engaged_start) places it. M5 must come back well past its start, against
# friction (hence jaw.move_current). M2 then closes onto M5 and stops at the touch.
jaw.m5_step_offset 107           # UNMEASURED (forceps value); default if the adapter has no entry
jaw.m2_step_offset 139           # UNMEASURED (forceps value); only a cross-check (M2 is placed by contact)
jaw.m2_contact_offset -98        # tool-wide DEFAULT for adapters without <adapter>.m2_contact_offset (from 6 psm2 runs)
jaw.m2_apply_contact_offset true  # needle driver: the contact fires ~200 ticks PAST the true touch (still moving at the
                                 # current limit; psm2 4 Nov), so M2 moves back to contact - m2_contact_offset after it
jaw.m2_center_snap_max 400       # after the contact, snap M2 to <adapter>.m2_center_angle within 400 (tilted PSM1 runs: ~205)
jaw.m5_center_snap_max 1000      # step mode: snap M5 to <adapter>.m5_center_angle unless the step is wildly off (PSM1: the
                                 # step-to-center distance varied 78-350, the true center only ~100) -> nearly always snap
jaw.m5_engaged_start -246        # tool-wide DEFAULT for adapters without <adapter>.m5_engaged_start (from 6 psm2 runs)
jaw.engaged_trend 1.10           # M5 "engaged at start": current climb 450-600 vs 150-300 ticks
jaw.m2_engaged_trend 1.06
jaw.m5_engaged_mid 1.025         # ... and already climbing at 300-450 (else a step starting: keep sweeping)
jaw.m5_defer_travel 1300
jaw.stop_after_step 450
jaw.check_tol 80                 # M2 step vs contact disagreement that raises a JAW FLAG
jaw.wall_current 150             # held jaw's current while the other closes onto it
jaw.collapse_ratio 0.8           # contact = at current limit AND speed < ratio x cruising
jaw.goto_push_ratio 0.15         # M5 move back: nearly stalled at the limit = blocked
